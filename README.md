# ThousandEyes Enterprise Agent Migration

See [TE_AGENT_MIGRATE_MINIMAL_REQUIREMENTS/README.md](TE_AGENT_MIGRATE_MINIMAL_REQUIREMENTS/README.md).

From this folder, start a preview with `./run.sh` on macOS/Linux or `./run.ps1` in Windows PowerShell.
Add `--apply` to migrate after reviewing the preview. The tool prompts for credentials and confirmations.

For detailed preparation and recovery, see the
[operations runbook](TE_AGENT_MIGRATE_MINIMAL_REQUIREMENTS/docs/OPERATIONS.md).
